# Курсы 5fox

Интерактивный сайт с информацией о курсах, созданный с использованием Vue.js и генеративного ИИ.

## Демо

Посмотреть живую демонстрацию можно здесь: [https://ваше-имя-пользователя.github.io/course_site_test/](https://ваше-имя-пользователя.github.io/course_site_test/)

## Особенности

- Современный адаптивный дизайн
- Красивые анимации и переходы между страницами
- Интерактивная навигация
- Оптимизация для мобильных устройств

## Технологии

- Vue 3 с Composition API
- Vue Router
- Vite
- CSS анимации
- Intersection Observer API для анимаций при прокрутке

## Локальный запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/ваше-имя-пользователя/course_site_test.git
cd course_site_test
```

2. Установите зависимости:
```bash
cd frontend
npm install
```

3. Запустите dev-сервер:
```bash
npm run dev
```

4. Откройте http://localhost:5173 в вашем браузере

## Сборка для продакшена

```bash
cd frontend
npm run build
```

Собранные файлы будут находиться в директории `frontend/dist`

## Деплой на GitHub Pages

Проект настроен для автоматического деплоя на GitHub Pages с использованием GitHub Actions.

1. Убедитесь, что в файле `vite.config.js` значение `base` соответствует имени вашего репозитория.
2. Пушите изменения в ветку `main`.
3. GitHub Action автоматически соберет проект и выполнит деплой на GitHub Pages.
